# Treinamento CX — Informações Gerais & Atualização Cadastral

**Márcia Treinamentos × Ateky Internet**  
Material interativo para o setor de Customer Experience (CX).

## Para quem

Especialmente preparado para **Maria** e ao time de CX.

## O que contém

- Quando abrir o atendimento INFORMACOES GERAIS / ATUALIZACAO CADASTRAL
- O que analisar antes de abrir (regra do endereço)
- Passo a passo de abertura no sistema (com mock visual)
- Informações oficiais das lojas (horários, quem aceita dinheiro, atendentes)
- **Simulação interativa** de 3 atendimentos reais
- Checklist de excelência
- Quiz de fixação
- Analogias do dia a dia (metodologia Márcia)
- QR Code de avaliação
- Fontes originais da Wiki Ateky

## Deploy

Repositório pronto para Vercel (Framework: Other / Static).

## Identidade visual

Padrão Márcia Treinamentos / Ateky (navy + azul + cards limpos).
